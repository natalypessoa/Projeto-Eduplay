# EduPlay Comunitário 🛝

Sistema de gerenciamento criado em Java para organizar cadastros e o fluxo de frequência em um ambiente comunitário infantil.

## Como funciona
A aplicação foi desenvolvida aplicando conceitos de Programação Orientada a Objetos (POO) e conta com:
- Operações de **CRUD** completas (cadastrar, listar, atualizar e remover).
- Interface gráfica feita com **Java Swing**.
- Estruturação de dados própria com manipulação de arrays e controle de índices, sem usar bibliotecas prontas.
